Mapping Visual Boxes to Semantic HTML Containers

Before writing a single line of CSS, the wireframe was decomposed into logical regions. Rather than relying on generic <div> soup, each wireframe rectangle was assigned an explicit semantic role to establish a clear document outline.

Step 2: Responsive Reflow Strategy 4 min read

Adapting Across Desktop, Tablet, and Mobile Breakpoints

Static wireframes often depict only a single desktop viewport. To make the web page truly responsive, each grid container transitions gracefully across screen widths while maintaining touch target sizes of at least 44px × 44px.

Viewport Tier Media Query Grid Columns Navigation Behavior
Desktop > 1024px 12-col / 3-col / 2:1 Split Full horizontal bar + CTAs
Tablet Landscape ≤ 1024px 2-col Cards / Stacked Hero Compact horizontal bar
Tablet Portrait ≤ 768px 2-col Metrics / Stacked Aside Collapsible Hamburger Drawer
Mobile Phone ≤ 480px 1-col Single Flow Full-width touch buttons
